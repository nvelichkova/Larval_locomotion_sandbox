How the model works

This page describes every mechanism in the simulation: what is modelled, the equation, and the code that implements it. The code excerpts are not copies. They are read from this page's own <script id="model"> block each time this view opens, so they always match the model that is running. Symbols in the equations are tied to the sliders by their internal key, shown like this: per. Values shown as are the current slider settings.

1. Overview and the simulation loop

The model is kinematic, not dynamic. There are no forces, masses or torques. At each step the model sets the body's shape from muscle activity (segment shortening and intersegmental bend angles). It then finds the position of that shape in the arena by a weighted best fit to where the body was a moment earlier. The weights stand for how firmly each part grips the substrate. Grip resists backward sliding much more than forward sliding, so a contraction wave that passes along the body moves it forward. Crawling, stride length and turn angle all come out of this; none of them is imposed directly.

Time step

The simulation advances in fixed steps of h = 2 ms. Each animation frame takes the elapsed real time (capped at 50 ms), multiplies it by Sim speed spd, and runs as many 2 ms steps as fit (at most 6000 per frame). Results therefore do not depend on frame rate or Sim speed. The batch runner and the Node tools drive the same function on simulated time.

n = round(Δtframe · spd / h),  h = 0.002 s

Order of operations in one step

stepSim(dt) runs these stages in order:

  1. Fire relay events that are due: peristalsis.
  2. End a pause whose time is up; start a new wave if the body is crawling and the previous wave has left the body; possibly enter a pause.
  3. Update the commanded bend for the current state: head sweep, held turn, weathervane or relaxing (bending).
  4. Update wall deflection and postural curvature.
  5. Build the body shape in its own frame (localShape).
  6. Compute contact weights; place the body by weighted rigid fit; re-fit with backward friction (contact).
  7. Migrate the turning bend backwards along the body.
  8. Push the body out of the walls and trigger the wall response; update habituation (boundary).
  9. Update heading and local substrate; run the patch-leaving accumulator and visit bookkeeping (patch leaving).
  10. Score border time, finished turns, path length and speed; start a spontaneous turn if the run is over.
  11. Every 0.05 s of simulated time, write a frame to the replay buffer.

2. The body

The body is a chain of 11 segments, T1–T3 and A1–A8, total length L = 4 mm at rest, so each segment is s = 4/11 ≈ 0.364 mm long. The chain is described by 12 midline points: index 0 is the head, 1–10 are the intersegmental boundaries (T1/T2 … A7/A8), and 11 is the tail. Segment i runs from point i to point i+1. The bend angle βb sits at boundary b = 1…10.

Width

The width profile BODYW was measured from hand-labelled landmarks on both body margins (116 frames, 3 recordings). It peaks at A2/A3, and head and tail are tapered to 0.30. It is used twice:

  • for drawing: half-width = 0.38 mm × BODYWj (cosmetic only);
  • for mechanics: the two ventral denticle bands sit at ±rsp × BODYWj from the midline (see contact). At the default rsp = 0 the body is mechanically a line.

Heading and derived angles

ψ = atan2(y3 − y11,  x3 − x11)  (tail → T3/A1)
head direction = atan2(y0 − y2,  x0 − x2),  head angle = wrap(head direction − ψ)

The heading ψ uses the body behind the thorax, so a head sweep does not change it; the centroid is the mean of all 12 points. Every position and speed measure is taken from the centroid.

3. Peristalsis

The relay

A wave is a chain of discrete activation events passed from segment to segment. When segment i fires at time t, its contraction starts, and with probability rel the next segment is scheduled to fire after the intersegmental lag del. Forward waves (d = +1) start at A8 and run forward to T1; backward waves (d = −1) start at T1 and run back to A8. If the relay fails, the wave stops part-way along the body.

ton,i−d = ton,i + del  with probability rel

Contraction time course

Each contraction lasts dur and follows a raised cosine, peaking half-way through:

u = (t − ton,i) / dur,  ci(t) = ½(1 − cos 2πu) for 0 ≤ u ≤ 1, otherwise 0

Contraction shortens the segment. Peak shortening is amp (fraction of rest length):

ℓi = s (1 − amp · ci)

The ratio dur/del sets how many segments are contracting at the same time. At the current settings that is .

Wave timing

A new wave can start only when both conditions hold:

  • the stride period has elapsed since the last wave began: t ≥ t0 + per × (1.35 if backward) × (0.85 during local search);
  • the previous wave has left the body, meaning its last segment has finished contracting: t ≥ t0 + 10·del + dur.
Twave = max( per · fback · fsearch,  10·del + dur )

At the current settings the second term is  s and the stride period is  s, so the actual interval between waves is  s. When the second term is larger, it sets the rhythm and the Stride period slider has no effect.

Stride

Stride length is not a parameter. At each wave start the model measures how far the centroid moved since the previous wave start, and keeps a running mean of values between 0.005 and 3 mm. This mean is the "Stride mm" readout. It is also used to convert a target speed into a stride period (see substrates).

4. Substrate contact and body placement

This is the core of the model: how a change of shape becomes movement across the substrate.

Contact weights

Each midline point j has a contact weight wj: how firmly it holds its position. A point is released while either neighbouring segment contracts (the protopodia lift into a travelling pocket):

wj = 1 − lift · max(cj−1, cj)

During a head sweep the front of the body lifts. The fixed profile CASTC runs from 0.05 at the head to 1 from A2 backwards, and hl sets how much is released:

wj ← wj · (1 − hl (1 − CASTCj))  (cast only)

The mouth hooks anchor the head as a forward wave reaches it:

w0 ← w0 + mh · c0  (forward crawling only),  then wj ← max(0.02, wj)

Placement: weighted rigid fit

The new shape pj is built in the body's own frame. It is then placed in the arena by the rotation R(θ) and translation that best match the previous world positions qj, weighting each point by its grip. This is the weighted Kabsch (Procrustes) problem in two dimensions:

minimise  Σj wj ‖ R(θ)(pj − p̄) + q̄ − qj ‖2

where p̄, q̄ are the weighted centroids. With rj = pj − p̄ and q′j = qj − q̄, the best rotation has a closed form:

a = Σ wj (rj · q′j),  b = Σ wj (rj × q′j),  θ = atan2(b, a)
xj = q̄ + R(θ)(pj − p̄)

Firmly gripping points barely move, and released points go wherever the new shape puts them. When the rear grips and the front is released, a contraction pulls the rear forward less than it pushes the front.

Anisotropic friction

Denticles point backwards, so a larva slides forward much more easily than backward. After the first fit, the model checks each contact's displacement against the heading û = (cos ψ, sin ψ). Any contact that would slide backward has its weight multiplied by mu, and the fit is solved once more:

if (xj − qj) · û < 0 :  wj ← mu · wj;  re-fit

This asymmetry is what makes peristalsis move the body forward overall. With mu = 1, forward and backward slip cost the same and the body stays roughly in place. The denticles are fixed to the body, so the test always uses the body axis, including during backward crawling.

Denticle rows and grip asymmetry (optional)

When rsp > 0 the body has two contact rows, offset ±rsp·BODYWj along the local normal n̂j (from a central difference of the midline). The fit and the friction test then use all 24 row points. Each side of a segment can slip on its own, so a bend has a pivot.

asym lets the inside of a bend grip harder than the outside, in proportion to the normalised local bend κj = βj / (ca/ext), clipped to ±1:

a = clip(asym · κj, ±0.95),  wL,j = wj(1 + a),  wR,j = wj(1 − a)

The code records this as measured and refuted: a 39:1 grip ratio changes the fitted rotation by less than 1%. It is kept as a test instrument and is off by default. With rsp = 0 the fit is bit-for-bit the original line-body fit.

5. Body shape and bending

Building the shape

The shape is built from the tail forwards. The tail sits at the origin, and each segment points in the direction given by the sum of all bend angles behind it:

φi = Σb=i+110 βb,  pi = pi+1 + ℓi(cos φi, sin φi),  p11 = (0,0)

Each bend angle is the sum of three parts: the commanded bend (head sweep, turn or weathervane) times its profile, plus postural curvature and wall deflection spread evenly over all 10 boundaries:

βb = B · g(b) + (κpost + κwall) / 10

Bend profile

The commanded bend B is spread over the first E = ext boundaries with Gaussian weights, normalised to sum to 1:

BWk ∝ exp( −((k − 1) / (0.52 E))2 ),  k = 0 … E−1,  Σ BWk = 1

The profile is shifted back along the body by δ (bendPos) and linearly interpolated: g(b) = BW(b − 1 − δ). With bexit = 1 (default), the part of the profile that has moved off the tail is simply lost, so rotation fades out smoothly. With bexit = 0 the remaining part is renormalised to sum to 1. This keeps the whole commanded bend on the body until the very end, which ends in a sharp kink at A7/A8.

What drives the commanded bend B

  • Cast (head sweep): B = σ · Acast · ½(1 − cos 2π min(v,1)), with v = 0.6 (t − tsweep). One sweep lasts 1/0.6 ≈ 1.67 s and peaks at 0.83 s. σ = ±1 is the side. See turning.
  • Turn straightening (after an accepted sweep): B is held at its value at acceptance while the profile migrates backwards (below).
  • Run (weathervane): a slow sinusoidal target with phase rate 0.9 rad/s (period ≈ 7 s). B relaxes towards it at rate sr:
    Btarget = wv · sin ω,  ω ← ω + 0.9 dt,  B ← B + (Btarget − B) min(1, sr·dt)
  • Back / pause: B relaxes to 0 at rate 1.5·sr.

Bend migration: how a sweep becomes a turn

Once a sweep is accepted, the bend is held and its profile travels backwards along the body, and the body crawls through it. Rotation happens because the bend moves while the body advances and the placement fit re-orients the body each step. There are two ways to set how fast δ moves:

migV > 0:  δ ← δ + migV·dt   otherwise:  δ ← δ + migK · ‖Δcentroid‖ / s

With the default migV = 0, migration is tied to distance crawled. A bend that stays fixed in the world corresponds to migK = 1 (follow-the-leader). Straightening ends when δ > 10 + E; then B is set to 0.

Postural curvature

Real crawling carries a slowly wandering, body-wide bend, so runs curve. This is an Ornstein–Uhlenbeck process r with correlation time τ = cbt. Its noise is uniform on [−1,1], which has variance 1/3, so the noise amplitude is chosen to give a stationary standard deviation of exactly cbs:

r ← r − (r/τ) dt + σ √dt · U(−1,1),  σ = cbs √(6/τ)  ⇒  SD(r) = cbs

A raw OU process is rough from step to step, and the placement step turned that roughness into spurious forward speed. So the curvature actually used is passed through a further first-order lag with time constant τ/8:

κpost ← κpost + (r − κpost) min(1, dt / (0.125 τ))

Wall deflection

While the head pushes into a wall (inward normal n̂), a bend builds toward the nearer of the two wall tangents. Its size scales with how head-on the approach is:

drive = −û·n̂,  κtarget = wdf · min(1, drive) · sign(nearer tangent),  κwall relaxes to it with τ = 0.3 s

Off by default (wdf = 0).

6. Turning

When a turn starts

Run durations are exponential. When a run ends (and Spontaneous is on), the larva starts casting:

Trun ~ Exp( mean = rt × (lsi during local search) × (0.3 after the leaving decision) )

Head sweeps

Entering a cast clears the relay queue, so peristalsis stops and the larva sweeps its head in place. At the peak of each sweep (v = 0.5) the sweep is judged:

  • near a wall it is acceptable only if the new direction ψ + B points away from the wall (component along the inward normal > 0.3);
  • an acceptable sweep is accepted with probability acc, or always on the 5th sweep.

If the sweep is not accepted by the time it finishes, the next one goes to the other side and is larger:

A1 = ca,  Ak+1 = min(Ak · cg, 145°),  side alternates

Near a wall, from the 4th sweep on the side is set by the wall rule (below), and after 8 sweeps the larva backs up for 2 waves.

Which side the first sweep goes

chooseDir checks these rules in order; the first that applies wins:

  1. Leaving decided (patch arenas): turn toward the direction pointing out from the patch centre.
  2. Local search: with probability lsb, turn toward the point where the larva left the patch.
  3. Patch edge: turn toward the nearest food patch centre with probability pin, which peaks at the patch edge (distance d from centre, radius R):
    pin = 0.5 + (pb − 0.5) exp( −((d − R) / (0.45 R))2 )
    This is 0 in uniform arenas, on agar-only patches, and once leaving is decided.
  4. Handedness: +1 with probability hd, otherwise −1.

If the patch-edge draw fails, the code falls through to handedness rather than turning outward. So the real chance of turning inward at the edge is pin + (1 − pin) × P(handedness happens to point inward). That is about 0.975 at pb = 0.95 and hd = 0.5.

"Turn toward angle α" means side = sign(wrap(α − ψ)).

Turn scoring

The turn angle is the heading change from the start of casting to the end of straightening (or 25 s after acceptance, whichever comes first): Δψ = wrap(ψend − ψcast start). Each turn is logged with the number of sweeps and the substrate.

7. Pauses

Each time a forward wave starts, the larva may pause instead, for an exponentially distributed time with mean 1.5 s. The per-wave probability is chosen so the expected fraction of time spent paused equals pf. With wave interval T = per, the paused fraction is 1.5p / (T + 1.5p) = f, which gives:

ppause = min( 1,  pf · per / (1.5 (1 − pf)) ),  duration ~ Exp(1.5 s)

This uses per as the wave interval. When the wave-length gate makes the interval longer (see wave timing), the realised pause fraction is lower than pf.

8. Arena boundary

Contact geometry

  • Collision: if any point is within 0.22 mm of a wall, the whole body is shifted back in (largest penetration on each axis).
  • Near wall (nearWall): any point within 0.30 mm; returns that wall's inward normal.
  • Head touch (intoWall): the head point is within 0.5 mm of a wall and pointing into it (head direction · inward normal < −0.15). A tail near the wall, or crawling along it, is not a touch.

Response

When the body is pushed back from the wall during a run, the head is touching, and the 2 s refractory period has passed, the response depends on the current habituation tier:

TierHabituation HResponse
3> 0.66Reverse: back up 2 waves. Then cast with probability rvp, otherwise resume running
20.33–0.66Cast, first sweep toward the escape side
10.12–0.33Pause, Exp(0.8 s)
0≤ 0.12None: keep crawling along the wall

The "Stop & cast" header button caps the response at tier 2. Escape side: with wdf = 0, turn toward the side of the wall's inward normal (away from the wall); with wdf > 0, turn toward the nearer wall tangent (slide along it).

rvp is flagged in the code as guessed, not measured: tracking fails at the boundary, so no data constrain it.

Habituation

H ∈ [0,1] starts at 1. It decays while the head is touching and recovers once clear. Recovery speeds up with the number of contacts n:

touching:  H ← H · e−dt/tdes;  at the start of each touch: n ← n+1, H ← H · e−cdose/tdes
clear:  n ← 0 after 8 s clear (end of bout);  τ′ = max(0.05, tres · e−rgain·max(0, n−1)),  H ← H + (1 − H) min(1, dt/τ′)

A touch starts when the head first presses into a wall. If the head comes back within 0.5 s of the previous touch ending, it counts as the same touch and gets no new dose. Contacts within a bout speed up recovery; 8 s clear of the wall ends the bout.

The four genotype buttons (WT, rut, dnc, cam0) set (tdes, tres) to (18.9, 5.3), (5.2, 3.6), (14.3, 9.8) and (25.6, 6.5) s.

9. Substrates and food patches

Arena layouts

The arena is aw × ah mm. The patch radius is R = min(pr, 0.30·min(W,H)). Patch centres:

  • 1 patch: arena centre.
  • 2 patches: (W/2 ± dx, H/2), dx = min(0.26W, W/2 − R − 1).
  • 4 patches: (W/2 ± ox, H/2 ± oy), ox = min(0.24W, W/2−R−1), oy = min(0.26H, H/2−R−1).
  • Mixed: alternate patches carry the other food (yeast ↔ sucrose), diagonally in the 4-patch layout.

The local substrate is the food of the nearest patch if the centroid is inside it, otherwise agar.

Measured kinematics by substrate

Target speed and turn rate come from the means measured by Wosniack et al. 2022:

Turning a target speed into model settings

Whenever the local substrate changes, applyLocal sets three sliders (shown in amber) so the larva's mean speed matches the target v. With measured stride S (0.61 mm before any stride has been measured) and minimum wave span Tmin = 10·del:

per = clamp(S/v,  Tmin,  1.6 s),  pf = clamp(1 − v / (S/per),  0,  0.7),  rt = 60 / turns-per-min

If the stride period alone can't slow the larva enough (it hits the 1.6 s cap), the remaining slow-down is made up with pauses. The visit counter goes up each time the larva steps onto a food different from where it was.

Food quality Q is agar 0, sucrose 0.5, yeast 1. It is used by the leaving decision and by local search.

10. Patch leaving and comparative memory

How long the larva stays on a patch is not set directly. On food, a decision variable x accumulates evidence for leaving (a leaky drift–diffusion, Ornstein–Uhlenbeck process, kept at or above 0). The larva decides to leave when x reaches 1:

x ← max(0,  x + (μeff − oulk·x) dt + ounz √dt · U(−1,1))
μeff = max( 10−4,  oumu (1 − ouq·Q) · (1 + ocmp · m(t) · (Qmem − Q)) )
m(t) = e−(t − tmem)/tmem  (0 before the first visit)
  • Quality: better food lowers the drift, so the larva stays longer.
  • Comparison: the drift is scaled by how the current patch compares with the remembered one. After a poorer patch (Qmem < Q) drift falls and the larva stays longer; after a better one it rises. Equal qualities give no effect, which is the published negative control.
  • The uniform noise has variance 1/3, so the effective diffusion amplitude is ounz/√3.

Once x ≥ 1 (leaving): the inward edge bias switches off, turns aim out of the patch, and runs are 0.3× as long.

Visits

  • A visit starts when the centroid first stands on a food patch, and records which patch.
  • Stepping off starts a pending exit, labelled decision if x had reached 1, otherwise wander.
  • Returning to the same patch cancels the pending exit. Entering a different patch closes the old visit.
  • A pending exit becomes final once the centroid is more than vmerge mm outside its patch edge, or vtime s have passed off it.
  • Closing a visit records residence = exit time − entry time, then sets the memory Qmem to this patch's quality, tmem = now, and resets x.

Visit log columns: entry time, residence, substrate, quality, previous quality, memory weight, exit type, and time from entry to the leaving decision. The last column measures the decision alone, without the walk out of the patch.

11. Local search

When the larva steps from food onto agar (and lsd > 0), it records the exit point and starts a period of local search. The period is longer after better food:

TLS = lsd · (1 − lsq + lsq·Q),  lsq = 0.6 (no slider)

During local search:

  • mean run length × lsi (more turns);
  • wave interval × 0.85 (faster crawling), unless the wave-length gate already sets a longer interval, as it does on agar at default settings (see notes);
  • with probability lsb a turn aims back at the exit point (default 0: the code notes that aiming lowered patch residence).

Search ends early on reaching food again.

14. Notes from reading the code

Places where the code, comments or tooltips disagree, or where behaviour is not obvious. None of these have been changed.

  1. Wave interval vs stride period. A wave can only start once the previous one has left the body, after 10·del + dur (1.5 s at defaults). applyLocal limits the stride period from below using 10·del only (0.9 s), without dur. On agar it sets the period to that 0.9 s floor (the slider's written value of 1.07 is replaced as soon as the page loads). So on agar and sucrose the gate, not "Stride period", sets the crawl rhythm: waves come every 1.5 s, not every 0.9 s. The speed matching and the pause fraction are both computed for a period that is never reached. The same gate also cancels the local-search speed-up (wave interval × 0.85) whenever it sets the rhythm.
  2. Hidden parameter. lsq = 0.6 (how much patch quality lengthens local search) has no slider and cannot be set from the batch runner.
  3. Inward bias is stronger than pb. A failed inward draw falls back to handedness, which points inward about half the time (see turning).
  4. Memory time stamp. tmem is set when the visit closes, which can be up to vtime after the larva actually left. The memory therefore starts decaying a little later than the departure.
  5. Markup. The "Handedness H" label has a misplaced <span> inside its tooltip, so the tooltip text shows "<span>". Some value labels (e.g. Contract. amp, Contract. dur) are written with placeholder numbers that the script overwrites on load. This is harmless.
